## 📝 Problem Description

Petya loves comparing strings. He compares two strings **lexicographically**, ignoring case.

You're given two strings of equal length. You must compare them and determine:
- `-1` if the first string is **smaller**
- `1` if the first string is **greater**
- `0` if both strings are **equal** (case-insensitive)

---

## 📥 Input Format

- Two strings `a` and `b`, both consisting of lowercase or uppercase Latin letters.
- The lengths of the strings are equal and range from `1` to `100`.
